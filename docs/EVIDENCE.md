# Evidence and future research

| Evidence class | What exists here | What it supports |
|---|---|---|
| Synthetic raw candles | Deterministic native indicator/rule replay; zero trades retained | Pipeline, missing-data and causal-processing inspection |
| Engineered features | One accepted losing trade, nearby-target rejection, frozen-rule cost stress | Rule, cost/risk and cash-accounting correctness cases |
| Recorded private findings | Narrative only: two hypothetical baseline trades; ten weekly folds, nine with no trades | Explains historical limitations; not independently reproduced in this export |
| Real reproducible research | None included | No market-edge or profitability conclusion |
| Recovery research | Excluded implementation; proposed, synthetic-only, unselected | Future proposal only |
| Source/clock qualification | Real package gate unresolved/failed qualification | Blocks qualified empirical interpretation |

The two baseline trades and overlapping weekly observations do not supply independent confirmation of profitability. Selected personal paper trades were a different manual accounting study and are excluded. Only the standalone demonstration suite supplies current verification; earlier research test counts are not inherited.

The engineered acceptance target is deliberately generous; the nearby-target variant demonstrates rejection. These are authored conditions, not discovered predictive signals. The raw zero-trade result was not tuned away. The cost stress changes only cost multipliers. None supplies a confidence interval for returns or demonstrates parity with a live venue.

Before a real study: obtain explicit data redistribution rights or publish acquisition instructions; qualify source clocks/DST/arrival times and contracts; freeze hypotheses and every attempted variant; reserve genuinely new evaluation observations; define execution latency, spread/slippage/financing and independent cash checks; inspect no-trade/missing-data cells; quantify uncertainty with dependence-aware sampling. Previously examined periods remain development evidence. A positive future result would still need independent replication and out-of-sample qualification.
