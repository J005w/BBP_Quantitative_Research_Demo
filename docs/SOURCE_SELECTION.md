# Implementation scope

The demonstration selects one fixed continuation baseline with numerical and causal controls. It keeps indicator arithmetic, completed-bar views, confirmed pivots, sizing, risk limits, simulated accounting, cost scenarios and independent reference comparisons. Level lifecycle observations are diagnostic; they do not change nearest-target admission.

The fourteen core modules are `__init__`, `config`, `indicators`, `strategy`, `research_parameters`, `sizing`, `risk`, `paper`, `research_costs`, `execution_costs`, `research_levels`, `level_evidence`, `backtest` and `parity_reference`. The authored synthetic fixture supplies a separate engineered feature case. The offline reference comparator and its synthetic tests do not establish broker/platform parity.

Live adapters, account capture, history acquisition, manual-trade reconstruction, collectors and experimental execution workflows are excluded. Recovery, bounce and pilot strategies are not selected. Recovery research remains proposed and synthetic-only, without a qualified return experiment. The original real source-clock qualification gate remains unresolved.

The earlier two-trade hypothetical finding is recorded context only. It is not independently reproduced here, and overlapping weekly observations do not establish profitability. Personal records and raw market observations are excluded. The distributed raw candles and engineered features are invented correctness examples.

The suite checks future-data perturbation, delayed availability, pivot confirmation, replay parity, next-bar entry, gaps, stop/target ambiguity, quote-side accounting, costs, risk/margin caps, loss pauses, persistence, HTTP boundaries and separate cash arithmetic. Tests use no original Git metadata or private data. Configuration and source identities for this standalone implementation are recorded in each generated report.
